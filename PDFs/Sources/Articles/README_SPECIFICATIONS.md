# Official Specifications - Download Instructions

This document provides instructions for accessing the official specifications referenced in the thesis. Due to membership requirements and access restrictions, these documents need to be downloaded manually.

---

## 1. ETSI GS ZSM 016 - Intent-driven Closed Loops

**Document**: ETSI GS ZSM 016 V1.1.1 (2021-10)
**Title**: Zero-touch network and Service Management (ZSM); Intent-driven Closed Loops
**Status**: Freely available from ETSI

**Download Instructions**:
1. Visit: https://www.etsi.org/deliver/etsi_gs/ZSM/001_099/016/01.01.01_60/gs_ZSM016v010101p.pdf
2. The PDF should download directly (no registration required)
3. Save as: `ETSI_ZSM_016_Intent_Driven_Closed_Loops.pdf`

**Alternative Access**:
- Search ETSI Standards website: https://www.etsi.org/standards-search
- Search for "ZSM 016"

**BibTeX Key**: `etsi_zsm_016`

**Thesis Reference**: Section 2.1 (ETSI ZSM 016: The Intent-Driven Closed Loop)

## 2. TM Forum TMF921 - Intent Management API

**Document**: TMF921 Intent Management API User Guide v5.0.0
**Title**: Intent Management API TMF921
**Status**: Requires TM Forum membership or registration

**Download Instructions**:
1. Visit: https://www.tmforum.org/resources/specifications/tmf921-intent-management-api-user-guide-v5-0-0/
2. You may need to:
   - Create a free TM Forum account
   - Or request access through your institution
3. Save as: `TMF921_Intent_Management_API.pdf`

**Additional Resources**:
- TMF921A Intent Management API Profile: https://www.tmforum.org/resources/specification/tmf921a-intent-management-api-profile-v1-0-0/
- API Directory: https://www.tmforum.org/oda/open-apis/directory/intent-management-api-TMF921/v5.0
- GitHub (partial): https://github.com/tmforum-apis

**BibTeX Key**: `tmf921_api`

**Thesis Reference**: Section 2.3 (TMF921: The Intent Management API)

## 3. OCPP 2.0.1 Specification

**Document**: OCPP 2.0.1 (Open Charge Point Protocol)
**Title**: OCPP 2.0.1 Specification (Edition 3 or Edition 4)
**Status**: Requires Open Charge Alliance membership

**Download Instructions**:
1. Visit: https://openchargealliance.org/my-oca/ocpp/
2. You need to:
   - Create an OCA account (may require membership)
   - Or check if your institution has access
3. Download OCPP 2.0.1 Edition 3 or 4 (zip file contains multiple parts)
4. Save main specification as: `OCPP_2_0_1_Specification.pdf`

**Alternative Sources**:
- Some parts available at: https://downloads.regulations.gov/FHWA-2022-0008-0404/
  - Part 0 Introduction: attachment_3.pdf
  - Part 2 Specification: attachment_6.pdf
- GitHub implementations (see ESSENTIAL_REPOSITORIES.md):
  - mobilityhouse/ocpp (Python implementation with examples)

**License**: Creative Commons Attribution-NoDerivatives 4.0 International

**BibTeX Key**: `ocpp_201_spec`

**Thesis Reference**: Section 4 (The Evidence: Illigo/Energy Logs and OCPP 2.0.1)
